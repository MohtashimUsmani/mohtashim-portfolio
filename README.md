# Mohtashim Usmani Portfolio

A full-stack personal portfolio website built with **React.js** frontend and **Django REST Framework** backend to showcase my projects, skills, experience, and development journey.

## 🌐 Live Demo

[Live Portfolio Website](https://www.mohtashimusmani.me)

---

# 🚀 Features

## Frontend Features

* Modern responsive UI
* Smooth animations
* Interactive sections
* Mobile-friendly design
* Project showcase
* Skills section
* Contact section
* Social media integration

## Backend Features

* Django REST API
* API endpoints
* Static/media handling
* Production-ready configuration
* CORS configuration
* WhiteNoise static serving
